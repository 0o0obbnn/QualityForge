Gate 0 核心链

  • • 来源 → IR → 质量门禁 → 场景 → 设计链 → 验证
  • • 每个环节由独立原子 Skill 做确定性门控
  • • 产出物采用稳定根 + 不可变版本
  • • 所有跨域引用固定 ID + versionId + digest
  • • Agent 生成 → 独立验证 → 人工审核三段式

执行流程

  • • ExecutionPlanVersion 冻结执行上下文
  • • Scheduler 按 Runner 能力分配租约
  • • Runner 容器隔离 + 短时 Secret + 网络策略
  • • 每个 attempt 追加结果，重试不覆盖
  • • 质量分析异步创建，不修改执行事实

审核发布

  • • 锁定版本 + 重算授权 + 职责分离
  • • 校验 contentDigest 和 blockingChecks
  • • 追加 ReviewDecision + AuthorizationDecision
  • • humanOnly: 正式批准为人类专属能力
  • • 任何一步失败 → 事务回滚，不产生有效批准
