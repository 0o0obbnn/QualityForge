# QualityForge 品牌资产 · Logo(定稿「Q 之锻」)

## 正式 Logo · Q 之锻(矢量版)

- **文件**: `logo-qforge.svg`(矢量源) + `logo-qforge-v2.png`(1024² 渲染)
- **概念**: Q = Quality(质量); 270° 琥珀环 = 质量闭环; 右上缺口 = 被锻造击穿的开口;
  深炭凿形楔子 = 锻造之力(人工审核那一记重锤); 缺口外迸出的星火 = 品质在审核中淬炼升华
- **表达**: 「AI 起草, 人工锻造。质量, 在审核中成形。」
- **配色**: 琥珀铜渐变(#F2CD9E→#D96C1F→#B8551A)× 深炭 #1D1B18(禁蓝紫合规)
- **质量**: 手工矢量构建, 边缘绝对平滑, 无限放大不失真; 识图 8.8/10

## 设计要点

- 圆(闭环/完整)与楔(力/突破)的刚柔几何对比
- 缺口负空间 = 叙事开口, 星火 = 视觉焦点与品牌记忆点
- 非对称动态平衡; 小尺寸可辨认(星火在 favicon 级建议高亮色)

## 使用

- 登录页/看板入口已嵌入(深炭容器内展示)
- favicon 建议: 用 SVG 直接缩放; 星火在极小尺寸可提亮
- 需调整(环粗/缺口大小/楔形角度/星火位置) = SVG 参数级修改
