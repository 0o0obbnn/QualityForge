# 15-PRD-质量分析与缺陷

> 现行模块：质量分析与缺陷。文件名为兼容历史链接保留。Skill生命周期由16号AI Agent中心负责。

## 1. 目标与边界

把执行事实转成可审核的质量判断、Defect、报告和门禁建议，减少失败分析、提Bug和报告整理的重复劳动，同时避免AI推断污染执行事实或直接影响外部系统/发布。

## 2. 正式产出物

| 产出物 | 核心内容 | 人工责任 |
|---|---|---|
| ResultAnalysis | 结果引用、聚类/RCA、置信限制、替代解释、影响和建议 | 认可分析成立及边界 |
| Defect | 标题、复现、期望/实际、严重度、类型、环境、影响Release、Evidence | 认可问题、优先级和同步内容 |
| TestReport | 范围/执行/指标快照、结论、风险、限制和签署 | 对交付质量结论负责 |
| CoverageReport | 冻结范围与分母快照、已检查/偏差/未检查/不可判定数、规则/场景/状态/断言维度摘要（裁决 B2-1，2026-08-14） | 批准分母口径与报告结论 |

## 3. 功能需求

| 能力 | AI作用 | 人工控制 |
|---|---|---|
| 结果分析 | 聚类失败、关联日志/Trace、RCA和替代解释 | 审核证据充分性，不接受越界推断 |
| FailureCluster | 按特征聚合ExecutionResult，支持拆分/合并建议 | Cluster不是Defect，人工决定是否建Defect |
| Defect | 生成草稿、去重、复现步骤和严重度建议 | 批准版本、流转、关闭和重复关系 |
| 外部同步 | 生成固定payload、附件和操作建议 | 每次CREATE/UPDATE/COMMENT/TRANSITION等写入单独批准 |
| 报告 | 汇总冻结范围、执行事实、已批准分析/Defect和指标 | 签署发布，披露ERROR/阻塞/排除项 |
| 覆盖率 | 按批准分母口径与快照生成执行覆盖率报告；设计覆盖分析（需求→用例映射）归 12 号模块（裁决 B2-1，2026-08-14） | 批准分母口径与报告结论 |
| 质量门禁 | 执行版本化确定性规则，AI提供风险/回归建议 | 门禁规则变更、放行/阻断豁免由人决定 |
| 流水线 | 关联触发、运行、回调和回执 | 外部写入与触发范围受授权 |

## 4. 关键规则

- ResultAnalysis与ExecutionResult分离；分析可被推翻但结果事实不被改写。
- FailureCluster只聚合失败，不存外部缺陷键，不代表缺陷成立。
- Defect稳定根和不可变版本分离于生命周期状态；关闭/验证需要证据。
- 每个DefectSyncAttempt绑定DefectVersion、Integration、操作、payloadDigest、approvalId和幂等键。
- V1 手工外部同步同样创建 DefectSyncAttempt 记录并绑定批准（执行者为人，裁决 B2-4，2026-08-14），不绕过 EXTERNAL_WRITE 契约；回执与幂等键照常落库。
- TestReport必须固定scopeSnapshot和executionSnapshot，签署后内容不可变；更正产生新版本。
- CoverageReport是执行覆盖率正式产出物（裁决 B2-1）：按批准的分母口径与快照生成；设计覆盖分析（需求→用例映射）归12号测试策划与设计，两概念不共用实体。
- TestReport必须披露契约检查摘要（裁决 B2-2，2026-08-14）：采用的执行基线摘要、已检查 Operation 数、偏差数、未检查数与不可判定数。
- AI建议不能自动放行/阻断发布；确定性门禁规则也必须版本化和可解释。

## 5. 主流程

```text
ExecutionResult/Evidence → AI聚类和ResultAnalysis草稿 → 人工审核
→ AI生成Defect/TestReport草稿 → 人工批准/签署
→ 如需外部同步，逐次ReviewTask+AuthorizationDecision → SyncAttempt回执
→ 已审核经验提交KnowledgeEntry候选（V1 交付边界：AI 提炼草稿+人工发布；V2 起增强自动反馈，裁决 2026-08-14 批次二，对齐 05 §5.13.3）
```

## 6. 异常与降级

- Evidence不足/关联ID缺失：分析标记`INCONCLUSIVE`并请求补证，不制造确定根因。
- 外部系统冲突/超时：记录attempt和回执，重试使用同一幂等键，不假报成功。
- 报告数据快照变化：旧审核作废，创建新版本。
- 质量门禁依赖不可用：返回不可判定，不能默认放行。

## 7. 验收标准

### AC-01 聚类不等于Defect

- **Given** AI聚类出10个相似失败；
- **When** 聚类完成；
- **Then** 只产生FailureCluster/分析草稿，不自动创建已批准Defect或外部Issue。

### AC-02 外部写入逐次批准

- **Given** Defect创建同步已批准；
- **When** 后续要改变外部状态；
- **Then** 新建独立SyncAttempt并重新审核，旧批准不能复用。

### AC-03 报告分母透明

- **Given** TestReport展示通过率；
- **When** 存在ERROR、BLOCKED、SKIPPED；
- **Then** 报告显示完整分类、分母定义和排除理由，不把无效执行算PASS。

### AC-04 AI分析可被纠正

- **Given** 人工证据否定AI根因；
- **When** 审核退回；
- **Then** 新分析版本保留替代解释，原AI版本/证据仍可审计，ExecutionResult不变。

## 8. 版本范围

V1支持基础分析、Defect/报告草稿和人工审核；V2增强外部同步、门禁和流水线；V3增强风险预测，但所有高价值决定保留人工硬门。
