## 3. 关闭规则

1. `BASELINED`只能说明需求已进入权威资料。
2. `CONTRACT_PENDING`必须在39号目标契约基础上，经契约先行工作包同步32 OpenAPI、33 DDL和36实时事件后才能转为`IMPLEMENTATION_PENDING`。
3. `IMPLEMENTATION_PENDING`必须取得正常、异常、权限、取消/恢复和证据回读的运行时证据后才能转为`VERIFIED`。
4. 任何状态变化必须更新本表、35 CHANGELOG和对应验收报告；不得只在代码注释或交付报告中声明关闭。
5. 裁决到实施工作包的唯一编排见[40-V1目标契约激活与实现Backlog](../04-architecture/40-V1目标契约激活与实现Backlog.md)；实现时不得另建无裁决ID的平行任务口径。
