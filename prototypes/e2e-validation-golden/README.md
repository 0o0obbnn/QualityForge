# Gate 0 Golden E2E

This is the positive companion to `prototypes/e2e-validation/`, whose
incomplete coverage snapshot is intentionally retained as a negative gate
sample. The artifacts here form a minimal complete IR → scenarios → cases →
assertions → coverage chain and must finish with `GATE_PASS`.

Reports are regenerated by the corresponding checker CLIs and are evidence,
not hand-authored verdicts. Expected exits are zero for every command.

## Automated assertion

`prototypes/skills/tests/test_e2e_chains.py::GoldenChainTests` re-runs the
checkers against these inputs and asserts the terminal verdict is `GATE_PASS`,
that every dimension passes on a **non-empty denominator** (a pass earned on an
empty denominator would be a fake pass), and that the committed reports match a
live run. Run with `make test-skills`.

The negative companion under `prototypes/e2e-validation/` is asserted by the
same file and must stay `GATE_FAILURE`.

```bash
python3 prototypes/skills/ir-validator/scripts/validate.py \
  --ir prototypes/e2e-validation-golden/01-ir/testing_ir.json \
  --out prototypes/e2e-validation-golden/01-ir/validation_report.json

python3 prototypes/skills/scenario-generator/scripts/scenario_check.py \
  --scenarios prototypes/e2e-validation-golden/02-scenarios/scenarios.json \
  --ir prototypes/e2e-validation-golden/01-ir/testing_ir.json \
  --out prototypes/e2e-validation-golden/02-scenarios/scenario_report.json

python3 prototypes/skills/test-case-generator/scripts/case_check.py \
  --cases prototypes/e2e-validation-golden/03-cases/cases.json \
  --ir prototypes/e2e-validation-golden/01-ir/testing_ir.json \
  --scenarios prototypes/e2e-validation-golden/02-scenarios/scenarios.json \
  --out prototypes/e2e-validation-golden/03-cases/case_report.json

python3 prototypes/skills/assertion-generator/scripts/batch_check.py \
  --batch prototypes/e2e-validation-golden/04-assertions/assertions.json \
  --out prototypes/e2e-validation-golden/04-assertions/batch_report.json

python3 prototypes/skills/assertion-verifier/scripts/verify.py static-check \
  --assertions prototypes/e2e-validation-golden/04-assertions/assertions.json \
  --ir prototypes/e2e-validation-golden/01-ir/testing_ir.json \
  --out prototypes/e2e-validation-golden/04-assertions/static_report.json

python3 prototypes/skills/coverage-analyzer/scripts/coverage.py \
  --snapshot prototypes/e2e-validation-golden/05-coverage/snapshot.json \
  --strategy prototypes/e2e-validation-golden/05-coverage/strategy.json \
  --out prototypes/e2e-validation-golden/05-coverage/coverage_report.json
```
