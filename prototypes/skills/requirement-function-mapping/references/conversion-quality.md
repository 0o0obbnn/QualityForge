# 文档转换质量门禁

本 Skill 的权威输入是可定位的 Markdown。DOCX/PDF 转换属于输入适配步骤；转换器不是本 Skill 的内置依赖。

转换后必须生成一份清单，至少包含：源文件哈希、转换工具与版本、页数或章节数、标题数、表格数、图片数、失败对象和抽检位置。

## 停止精细提取的条件

满足任一条件时，将相关来源单元标为 `unavailable` 或 `review_required`，不得继续把缺失内容推断为需求事实：

- 无法建立稳定的标题、页码、段落或表格定位；
- 源文档存在表格，但转换结果无法保留单元格行列关系；
- 图片、附件或嵌入对象未导出且其中可能包含需求事实；
- 字符乱码、顺序错乱或公式丢失导致原文含义不可核验；
- 转换清单无法对账源文档与 Markdown 的章节、表格或图片数量。

数量阈值不得凭经验固定为统一百分比。若转换器能可靠提供源/目标对象计数，要求标题、表格、图片均逐项对账；任何未解释差异都进入缺口。若无法取得源侧计数，则至少人工抽检目录、首尾章节、每类表格和所有包含图片的章节，并把范围写入清单。
