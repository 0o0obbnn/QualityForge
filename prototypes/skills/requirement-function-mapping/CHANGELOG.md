- 将状态门禁明确为“范围路由”而非全局停止开关；正式流水线默认只交付 READY 测试切片，包级评审未完成不再压制已确认范围。

- 增加拒绝原地覆盖的历史产物元数据迁移器。
- 校验器增加结构化诊断输出并保留兼容的字符串错误列表。
- 变更影响模型支持可选测试用例节点及 `verifies` 关系。
- 增加转换质量门禁和生成目录忽略规则。
- 增加基于输入、脚本和输出哈希的统一流水线与断点续跑入口。
- 增加确定性全文刷新、陈旧实体清理和增量语义/测试失效清单。
